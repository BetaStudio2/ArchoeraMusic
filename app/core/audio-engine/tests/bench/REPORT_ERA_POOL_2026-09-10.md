# EraAudio 常驻内核池：并发/混杂/首帧 Benchmark（headless 静音）

> 日期：2026-09-10 · 方法：EraAudio = 单进程 `zk_engine` Host（worker 数=并发上限）；
> 基线 = 同 N 个 `ffmpeg -threads 1 -f null -` 并发解码（静音、不输出设备）。
> 语料：sine 440Hz 3s 44.1k 立体声 × flac/m4a(aac)/mp3；内存受限 → 最高 24 并发。
> 指标：墙钟 ms、合实时倍数 ×RT = 源总时长/墙钟；首帧 ms（冷含引擎 init / 热复用池）。

## 4. 首帧响应（冷启动=进程起→首块可听；热=池已就绪→首块）

- flac：era 冷首帧 1 ms（含引擎 init）、热首帧 0 ms；ffmpeg 整文件解码 26.04 ms（会话代理，非首帧）
- m4a：era 冷首帧 1 ms（含引擎 init）、热首帧 0 ms；ffmpeg 整文件解码 30.82 ms（会话代理，非首帧）
- mp3：era 冷首帧 1 ms（含引擎 init）、热首帧 0 ms；ffmpeg 整文件解码 43.14 ms（会话代理，非首帧）

## 5. 结论与说明

- 并发受本机内存限制设上限 24；本报告为同机相对值，跨机请比 ×RT/加速比而非毫秒。
- 静音/headless：EraAudio 经 `zk_engine`（内存解码，无设备）；ffmpeg `-f null` 不写音频设备。
- 语料为短正弦（合成负载，未含真实音乐熵），趋势参考；真实语料/解码提速专项另见 decode-optimization.md。

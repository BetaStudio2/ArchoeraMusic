# Phosphor Icons

This directory contains the complete six-weight TrueType font set for
Phosphor Icons:

- Regular
- Thin
- Light
- Bold
- Fill
- Duotone

Source package: `@phosphor-icons/web@2.1.2`

Source repository: https://github.com/phosphor-icons/web

Source package archive: https://registry.npmjs.org/@phosphor-icons/web/-/web-2.1.2.tgz

License: MIT, see `LICENSE`.

These files are kept as source assets for a later Flutter `IconData` mapping.
They are intentionally not registered in `pubspec.yaml` yet.
